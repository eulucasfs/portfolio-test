# Portfólio Pessoal

Meu portfólio pessoal, desenvolvido para apresentar meus projetos, conhecimentos e minha evolução na área de desenvolvimento de software.

O objetivo é reunir meus trabalhos em um só lugar, compartilhar o que venho aprendendo e facilitar o contato com pessoas e empresas interessadas no meu perfil profissional.

## 🌐 Acesse o projeto

🔗 [Visualizar portfólio](https://portfolio-test-kohl-nine.vercel.app/)

## 🎯 Sobre o projeto

Este projeto foi criado para desenvolver minha presença profissional na área de tecnologia e apresentar, de forma organizada, meus conhecimentos e projetos.

Além de funcionar como uma apresentação profissional, o portfólio também serve como um espaço para colocar em prática conceitos de desenvolvimento web e aprimorar minhas habilidades.

## 🛠️ Tecnologias

As tecnologias utilizadas podem ser consultadas no código-fonte do projeto.

- HTML5 — estrutura das páginas.
- CSS3 — estilização e layout.
- JavaScript — interatividade e funcionalidades.

## 🚀 Acesso ao projeto

O projeto está publicado na Vercel e pode ser acessado diretamente pelo navegador.

Para executar localmente, caso tenha acesso ao repositório:

1. Clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Execute o arquivo `index.html` no navegador ou utilize a extensão Live Server.
